# AI Study Assistant

AI Study Assistant is a MERN stack application that helps students study from uploaded PDF documents.

## Features

- User registration and login
- Secure JWT authentication
- Upload PDF documents
- View uploaded PDFs
- Generate AI summaries
- Generate quizzes
- Generate flashcards
- Generate study notes
- AI chat assistant
- User profile and settings

## Technologies Used

### Frontend

- React.js
- React Router
- Axios
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
- Groq API
- PDF Parse
